# jackdaw brand

The mark is a jackdaw perched on a branch, drawn from circles, triangles
and bars: a black cap and face, the pale eye and the grey nape that set
a jackdaw apart from other crows, on a blue badge.

| File | Use |
|---|---|
| `jackdaw-logo.svg` | Mark and name, for light backgrounds |
| `jackdaw-logo-dark.svg` | Mark and name, for dark backgrounds |
| `jackdaw-mark.svg` | The badge alone: icons, avatars, favicons |
| `jackdaw-mark-512.png`, `jackdaw-mark-1024.png` | The badge where SVG is not taken |

## Colors

| | |
|---|---|
| Badge | `#3D63F5` |
| Plumage | `#0A1838` |
| Body | `#14296A` |
| Wing | `#1E3A8E` |
| Nape | `#C5D3F0` |
| Branch | `#0A0F1C` |
| Name on light | `#14171C` |
| Name on dark | `#F2F4F7` |

The badge keeps its blue on any background. Leave space around it of at
least a quarter of its width, and do not recolor, stretch or crop the
bird.
